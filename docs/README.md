> [!CAUTION]
> Two rules hold everywhere in this repo:
>
> - **Use the unmodified *Legend of Zelda, The (USA)* ROM.** The wrapper rejects anything else by checksum.
> - **Never commit files from the randomizer.** Its license allows sharing only the original installer. `.gitignore` keeps `vendor/` and ROMs out; keep it that way.
